# Privacy Policy

**Plugin:** real-estate-asset-management
**Publisher:** Ruby Huang
**Effective date:** October 9, 2026
**Contact:** rubyh218@gmail.com

## Summary

This plugin does not collect, store, sell, or share your data. It runs entirely inside your own AI assistant session and on your own files.

## What the plugin is

The plugin is a set of written instructions, reference guides, templates, and local Python helper scripts for real estate and private equity asset management work: asset reviews, investor reporting, rent roll and T-12 analysis, valuations, debt covenant tests, and hold, sell, or refinance memos.

## Data the plugin handles

When you use the plugin, the assistant may read files you choose to provide, such as rent rolls, operating statements, budgets, loan documents, or fund cash flows. The helper scripts process those files on the machine or sandbox where your assistant runs and write the results (Excel workbooks and Word documents) to your working folder.

The publisher never receives this data. The plugin has no server, no database, no analytics, and no telemetry.

## Data sent to third parties

None. The scripts make no network calls and do not contact any external service, API, or server.

The only network access is a one time package install: if the Python libraries `openpyxl` or `python-docx` are missing, the assistant may install them from the Python Package Index (pypi.org) using pip. That request downloads software only. It does not send any of your files or content.

Your use of the AI assistant itself (for example ChatGPT or Claude) is governed by that provider's own privacy policy.

## Data retention

The plugin keeps nothing between sessions. Any files it creates are saved where you choose, and you control whether to keep or delete them.

## Children

The plugin is intended for business use and is not intended for people under 18.
